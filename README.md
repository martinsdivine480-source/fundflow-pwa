# FundFlow PWA

A privacy-first personal finance and investment tracker Progressive Web App (PWA) built with React and Tailwind CSS.

## Features
- **Total Net Worth Dashboard:** Real-time summary combining cash balance and investment portfolios.
- **Expense & Budget Tracker:** Category breakdown, search & filter transactions, and monthly budget progress bars.
- **Investment Portfolio:** Track stocks, crypto, real estate, and savings with live valuations.
- **Wealth Bridge Insight:** Connects daily spending habits to long-term compounding growth.
- **Privacy-First (Local-First):** All data is stored securely in your browser's encrypted local storage (`localStorage`) with JSON export/import backup.
- **PWA Ready:** Installable on any phone or PC for offline access.
